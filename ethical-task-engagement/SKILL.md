# Ethical Task Engagement

## Operating rule

Optimize for the user’s completed goal and wellbeing, not time spent or compulsive return. “Addictive” is an informal product request; translate it into satisfying, voluntary, repeatable use.

## Build the loop

1. State the goal and a user-selected stopping point.
2. Reduce the first action to one visible, reversible step.
3. Show truthful progress and the reason for the next step.
4. Give lightweight feedback that does not interrupt or pressure.
5. Save context and make resumption easy after a pause.
6. Close with a concise summary, optional reflection, and a clear stop action.

## Use

- Prefer a single recommended next action plus visible alternatives.
- Use progress bars only when the denominator is real and stable.
- Make streaks forgiving or omit them; never erase work because a user rested.
- Make reminders user-configurable with quiet hours and a one-tap stop.
- Use previews, undo, and drafts for consequential actions.
- Write short, direct, dyslexia-friendly copy with clear headings and strong contrast.
- Instrument completion quality, recovery, and opt-outs; do not reward endless sessions.

## Reject

- Gambling-like random rewards, artificial scarcity, fear of missing out, shame, manipulative social comparison, hidden autoplay, dark defaults, or notification escalation.
- Any mechanic that makes stopping, exporting, deleting, or changing settings harder than continuing.
- Any claim that a task is complete without durable evidence.

## Verification

Test keyboard, screen reader, reduced-motion, empty, error, offline, resume, undo, and “done for today” states. Report `FACT`, `INFERENCE`, and `NEEDS HUMAN CHECK` separately.
