# Addictive Development Skill

PatchworkMD skill for making productive action compelling and task completion satisfying. The implementation explicitly rejects gambling mechanics, coercion, dark patterns, harmful consumption loops, and compulsive-use optimization.

Highlights:

- Visible, truthful progress and one clear next action.
- Forgiving continuity, drafts, undo, and healthy stopping points.
- Accessibility, quiet hours, user controls, privacy, and exact-once backend state.
- Guidance for Hermes, replay, local-model benchmarking, and the existing anti-slop/UI/backend skill stack.
