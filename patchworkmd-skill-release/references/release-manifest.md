# Release candidate manifest

Record these fields in the export package:

- `package_name`
- `brand`: PatchworkMD
- `canonical_source`
- `included_paths`
- `source_revision_or_hash`
- `skill_validator_result`
- `test_result`
- `toolchain`
- `license_decision`
- `private_material_scan`
- `third_party_provenance`
- `publication_status`
- `human_gates`

Use `NOT CLEARED FOR PUBLICATION` when license, provenance, privacy, or human wording review is unresolved.
